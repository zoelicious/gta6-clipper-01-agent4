## The clip

Jason waits outside the prison gates as Lucia walks out — "DUA ORANG. SATU
RENCANA." Then the masked bank heist, a quiet golden-hour moment on the
pier, and a night chase through Vice City — before the clip turns to
make.fun: bikin klip kayak gini pakai AI, dapat uang di make.fun.

- **Hook (0–2 dtk):** Lucia keluar dari gerbang penjara, Jason menunggu.
- **Momen:** reuni penjara → rampok bank bertopeng → dermaga → kejar-kejaran malam.
- **Pitch:** teks on-screen + voiceover di dalam klip, di 17–24 dtk.
- **Format:** 1080×1920 vertikal, 24,4 dtk, Short.

## The video

`VIDEO.json` holds the public YouTube Shorts address. The video's
description carries the bounty's line, this account's play code
(`makefun-outpost-goose-holly`), and the referral

## The program

`main.ts` (Node 22) copies `VIDEO.json` from the repository root into
`$MAKEFUN_OUTPUT_DIR`:

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
